# VoiceCleanKit

**Автоматическая очистка голоса для видео: вырезает паузы и вздохи, выравнивает громкость, делает субтитры.**
Всё работает локально на вашем компьютере, без облака и без подписок.

> Описание для репозитория GitHub (одна строка): *Очистка озвучки для YouTube: вырезание пауз и вздохов, нормализация громкости, простой эквалайзер, субтитры (Whisper) и экспорт в Premiere Pro.*
> Теги (topics): `voice`, `audio`, `youtube`, `whisper`, `subtitles`, `premiere-pro`, `ffmpeg`, `windows`

## Возможности

- **Вырезание пауз и вздохов.** Детектор речи находит голос, всё лишнее удаляется. Короткие паузы сохраняются, длинные сокращаются до заданной длины и заполняются тихим шумом комнаты, чтобы склейки не звучали «мёртвыми».
- **Минимум обработки.** ФВЧ 50 Гц, мягкое приглушение тихих мест между словами (экспандер) и подгонка громкости до −14 LUFS (стандарт YouTube). Шумоподавление, компрессор и удаление щелчков отключены по умолчанию, чтобы не менять тембр.
- **Простой эквалайзер.** Три ползунка: низ, середина, верх.
- **Субтитры.** Расшифровка речи (faster-whisper) в `.srt` и `.txt` с таймкодами и список слов, в которых распознавание не уверено.
- **Видео и Premiere Pro.** Для видеофайла создаётся XML-секвенция: видео нарезано в тех же точках, что и звук.
- **Окно с настройками.** Пресеты, ползунки, перетаскивание файла, журнал работы.

## Что нужно

- Windows 10/11
- около 2 ГБ свободного места (Python, библиотеки, модель распознавания)
- видеокарта не нужна, всё считается на процессоре

## Установка

1. **Распакуйте архив** (ПКМ → «Извлечь всё»). Запускать файлы прямо из архива нельзя.
   Путь лучше без русских букв, например `D:\VoiceCleanKit`.
2. Запустите `1_INSTALL.bat`. Он поставит Python, FFmpeg и нужные библиотеки.
   Если после установки Python или FFmpeg окно просит «закрыть и запустить заново», так и сделайте.
3. Первая расшифровка скачает модель Whisper (около 500 МБ). Это один раз.

## Как пользоваться

### Окно приложения (рекомендуется)
Запустите `0_SETTINGS_AND_RUN.bat`.

1. Перетащите файл (аудио или видео) в окно или нажмите на зону, чтобы выбрать.
2. Выберите пресет или настройте ползунки на вкладке **Голос**.
3. На вкладке **Эквалайзер** подстройте тембр, если нужно.
4. На вкладке **Расшифровка** выберите модель и впишите названия игр и имена через запятую. Так Whisper пишет их правильно.
5. Нажмите **Обработать голос** (очистка и субтитры) или **Только субтитры**.
6. После завершения откроется папка с результатом. Настройки запоминаются.

### Перетаскивание на ярлыки
- `2_CLEAN_VOICE.bat`: перетащите на него файл, он обработается с эталонными настройками.
- `3_SUBTITLES.bat`: перетащите готовый ролик, получите субтитры.

### Что получится
Для каждого файла создаётся папка `projects\<имя файла>\`:

| Файл | Что это |
|---|---|
| `*_clean.wav` | очищенный звук |
| `*.cuts.txt` | что вырезано (таймкоды) |
| `*.srt`, `*.transcript.txt` | субтитры и текст |
| `*.lowconf.tsv` | слова, в которых распознавание не уверено: проверьте их на слух |
| `*_premiere.xml` | секвенция для Premiere Pro (если на вход было видео) |

## Настройки

| Параметр (окно / флаг) | По умолчанию | Смысл |
|---|---|---|
| Паузы не трогать до / `--keep-gap` | 0,2 с | паузы короче остаются как есть |
| Паузы сокращать до / `--pause` | 0,22 с | во что превращается длинная пауза |
| Чувствительность речи / `--vad-threshold` | 0,65 | выше: строже режет вздохи, ниже: не съедает тихие окончания слов |
| Запас вокруг слов / `--pad` | 0,06 с | тишина до и после слов |
| Затухание фразы / `--fade-out` | 0,12 с | плавный спад перед паузой |
| Громкость / `--lufs` | −14 | целевая громкость |
| Приглушать тихие места / `--expand` | вкл | фон между словами тише, речь без изменений |
| Низ / `--eq-low` | 0 дБ | плюс: теплее, минус: тоньше (120 Гц) |
| Середина / `--eq-mid` | 0 дБ | плюс: разборчивее, минус: мягче (3 кГц) |
| Верх / `--eq-high` | 0 дБ | плюс: ярче, минус: глуше (8 кГц) |
| `--denoise` | выкл | шумоподавление, только при заметном фоне |
| `--compress` | выкл | мягкий компрессор |
| `--declick` | выкл | удаление щелчков (может притупить согласные) |
| `--keep-breaths` | выкл | не обрезать вдохи в конце фраз |
| `--no-transcript`, `--no-render` | выкл | пропустить расшифровку / сборку MP4 |

**Пресеты в окне:** «Плотно» (короткие паузы, динамичный монтаж) и «Мягко» (естественный ритм: паузы 0,45 / 0,35 с).

Запуск из командной строки:
```
.venv\Scripts\python.exe voice_clean.py "видео.mp4" --keep-gap 0.2 --pause 0.22 --vad-threshold 0.65 --expand
.venv\Scripts\python.exe make_srt.py "ролик.mp4" --model small --lang ru --prompt "Path of Exile, ExileCon"
```

## Premiere Pro

Если на вход подано видео, рядом появится `*_premiere.xml`. В Premiere: **File → Import**, выберите этот файл. Получится секвенция: на V1 видео, нарезанное по тем же точкам, что и звук; на A1/A2 очищенный звук одним клипом. Исходное видео и `*_clean.wav` должны оставаться на своих местах: в XML записаны абсолютные пути.

## Стрим (OBS)

Нарезка и субтитры в прямом эфире невозможны, поэтому на стриме используется цепочка фильтров микрофона OBS (ПКМ по микрофону → Фильтры):

1. **Усиление.** Обычная речь должна доходить до −25…−18 дБ в микшере.
2. **Расширитель (Expander).** Порог −35 дБ, 4:1, атака 8 мс, отпускание 250 мс, детектор RMS. Убирает скрип стула и клавиатуру в паузах.
3. **3-полосный эквалайзер.** Низ +2 дБ, середина 0, верх +1 дБ.
4. **Компрессор.** Порог −18 дБ, 1,8:1, атака 30 мс, отпускание 250 мс, усиление на выходе около +4 дБ.
5. **Ограничитель.** Порог −1 дБ, отпускание 60 мс.

Сначала поднимите усиление микрофона в Windows (`Win+R` → `mmsys.cpl` → Запись → Свойства → Уровни), остальное добирайте фильтром «Усиление». Порог расширителя ставьте чуть ниже самых тихих ваших слов.

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| «The system cannot find the path specified» | вы запустили `.bat` из архива: распакуйте архив и запустите из папки |
| «Run 1_INSTALL.bat first» | сначала выполните установку |
| Установщик просит закрыть окно | это нормально после установки Python или FFmpeg: закройте и запустите ещё раз |
| «ffmpeg не найден» | закройте окно после установки FFmpeg или перезагрузите ПК |
| Не открывается окно приложения | выполните `1_INSTALL.bat` ещё раз, он доустановит недостающее |
| Расшифровка идёт долго | на процессоре это примерно 1–2 минуты на минуту речи, это нормально |
| Названия или имена записаны неверно | впишите их в поле «Названия и термины» или в `--prompt` |
| Режутся тихие окончания слов | уменьшите «Чувствительность речи» (например, до 0,5) |
| Остаются вздохи | увеличьте «Чувствительность речи» (0,65–0,7) |

## Ограничения

- Вздох, слитый со словом, или клик внутри слова могут остаться: речь режется только между фразами.
- Расшифровка Whisper иногда ошибается в названиях и именах. Слова с низкой уверенностью собраны в `*.lowconf.tsv`, их стоит проверить на слух.
- Импорт XML проверен на структуре и расчёте кадров, на вашей версии Premiere стоит проверить на коротком ролике.
